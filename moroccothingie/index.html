Next-Gen Moroccan Enterprise Workflow Architecture

🎯 Role & Objective

Robust, scalable, production-ready PostgreSQL database schema (with Prisma ORM definitions) for a mobile-first French/Moroccan-style ERP & POS application. Specifically tailored for small-to-medium businesses (SMBs) in Morocco.

🇲🇦 Localized Rules

  • Currency: MAD (Moroccan Dirham) stored in standard decimal formats DECIMAL(12, 2).
  • Taxation (TVA): Line-item level support for 20%, 10%, 14%, 7%, and 0% (exempt).
  • Legal Identifiers: Built-in fields for ICE (15 digits), IF, RC, and CNSS.
  • Sequential Codes: Enforced document numbering per fiscal year (e.g., DEV-2026-0001).

🛡️ Critical Schema Gaps Addressed

Stock Movement Atomicity

Inventory levels cannot drop below zero. Enforced via a `quantity Int @default(0)` coupled with a raw SQL migration check constraint CHECK (quantity >= 0) on the `WarehouseStock` table.

Price Snapshotting

Line items strictly store historical unit prices and TVA rates at the exact time of document creation. This protects financial records from retroactive changes if product pricing updates later.

Audit Logs & Immutability

Immutable audit trail built in via the `AuditLog` model to track invoice cancellations, stock adjustments, and administrative overrides.

Document Lineage (Partial Conversions)

Implemented via the parentDocumentId self-relation on the `Document` model. A Devis can convert into multiple partial BLs, and multiple BLs can aggregate into one Facture. This robust tree structure traces origin and avoids double stock deduction.
