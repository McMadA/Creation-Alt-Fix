- **[2026-08-30] Apache 500 Internal Server Error Oplossing (`portal.creationaltfix.nl/admin`)**: Oorzaak van de HTTP 500 fout op het portaalsubdomein gediagnosticeerd en permanent opgelost:
  1. **Directe Oorzaak (`AH00526`)**: In `crm/.htaccess` was een `<LocationMatch "^/(admin|status)/">` blok opgenomen. Binnen Apache is de `<LocationMatch>` directive **strikt verboden** in per-directory `.htaccess` context (uitsluitend toegestaan in server config `httpd.conf` en `<VirtualHost>`). Dit resulteerde in een onmiddellijke Apache configuratiefout (HTTP 500 Internal Server Error) bij elk verzoek naar het portaal.
  2. **Architecturale Oplossing**: Het ongeldige `<LocationMatch>` blok is verwijderd uit `crm/.htaccess`. De privacy- en noindex-beveiliging is nu modulair en correct opgelost via: (a) gerichte `.htaccess` bestanden in `crm/admin/.htaccess` en `crm/status/.htaccess` met `Header set X-Robots-Tag "noindex, nofollow, noarchive"`, (b) `<meta name="robots" content="noindex, nofollow, noarchive">` tags in de `<head>` van `crm/admin/index.html`, `crm/admin/project.html` en `crm/status/index.html`, en (c) `Disallow: /admin/` en `Disallow: /status/` regels in `crm/robots.txt`. Tevens is de gevoelige bestandenblokkade (`.env`, `.sql`, `.db`, `.log`, etc.) toegevoegd aan `crm/.htaccess`.
